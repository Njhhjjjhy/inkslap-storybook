# Shadows

Inkslap uses shadows sparingly. Cards have a single resting shadow; modals use a Material-style three-layer elevation; and there is **one signature treatment** — a brand-tinted shadow used only on primary blue card CTAs.

The signature shadow is the part of the system most worth protecting.

---

## Focus ring

The documented focus indicator. Two-layer ring: a white inner gap, an Inkslap Blue outer ring.

<div style={{ marginTop: '24px', padding: '40px', backgroundColor: '#F9F9F9', borderRadius: '12px', display: 'flex', gap: '24px', justifyContent: 'center' }}>
  <button style={{
    padding: '12px 28px',
    backgroundColor: '#FFFFFF',
    color: '#040404',
    border: '1px solid #040404',
    borderRadius: '8px',
    fontFamily: 'Inter, sans-serif',
    fontSize: '16px',
    fontWeight: 500,
    cursor: 'pointer',
    boxShadow: '0 0 0 2px #FFFFFF, 0 0 0 4px #0099DE',
  }}>
    Focused button
  </button>
</div>

The live site does not consistently show focus rings on its interactive elements. The documented standard is **2 px gap + 2 px brand-blue ring** on every focusable element. See **Guidelines → Accessibility**.

## Shadow tokens summary

| Token | Value | Use |
|-------|-------|-----|
| `--shadow-card-rest` | `0 2px 8px 0 rgba(0,0,0,0.06)` | Resting card |
| `--shadow-card-hover` | `0 2px 8px 0 rgba(0,0,0,0.1)` | Hovered card |
| `--shadow-brand` | `0 2px 8px 0 rgba(17,154,222,0.3)` | **Signature** — primary blue CTAs only |
| `--shadow-modal` | Three-layer Material elevation 24 | Modals, dialogs |
| `--shadow-focus` | `0 0 0 2px #FFFFFF, 0 0 0 4px #0099DE` | Focus ring |

---

## Rules

| Rule | Detail |
|------|--------|
| Use shadows sparingly | The system has only five tokens. Resist the urge to invent intermediate values. |
| The brand-tinted shadow is a signature | Reserve `--shadow-brand` for primary blue card CTAs. Do not apply it to outlined buttons, secondary actions, or non-CTA cards. |
| No outer-glow effects | No purple, no neon, no soft white glows. The system is grounded in subtle drop shadows only. |
| No `inset` shadows | Pressed states use colour shift, not inset shadows. |
| Focus is always brand blue | Focus rings use `--color-brand-blue`, regardless of element colour. |

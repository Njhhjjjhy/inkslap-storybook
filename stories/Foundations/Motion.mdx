# Motion

Inkslap's motion system is modest. The live site uses motion for three things: rotating hero slides, the infinite-scroll partner marquee, and a typewriter-style placeholder in the header search. No scroll-triggered reveals, no parallax, no hover effects of consequence.

The documented system adds a small set of duration and easing tokens so that any new motion stays consistent with what is already there.

## Easing

| Token | Value | Use |
|-------|-------|-----|
| `ease-out` | `cubic-bezier(0, 0, 0.2, 1)` | Elements entering — default for most UI transitions |
| `ease-in-out` | `cubic-bezier(0.4, 0, 0.2, 1)` | Elements that start and end on screen |
| `ease-emphasized` | `cubic-bezier(0.2, 0, 0, 1)` | Important state changes — modal entrance |
| `linear` | `linear` | Continuous motion — partner marquee |

---

## Standard transitions

```css
--transition-colors: color 150ms ease-out, background-color 150ms ease-out, border-color 150ms ease-out;
--transition-hover: all 150ms cubic-bezier(0, 0, 0.2, 1);
```

Apply `--transition-hover` to anything interactive. Apply `--transition-colors` to anything that changes colour but should not scale or transform.

---

## What animates on the live site

| Surface | Behaviour | Duration | Easing |
|---------|-----------|----------|--------|
| Hero carousel | Auto-rotate between 3 slides, slide-fade transition | ~500ms | `ease-in-out` (sampled) |
| Partner marquee | Continuous horizontal translate | constant | `linear` |
| Search placeholder | Typewriter-cycles through hint terms | ~80ms per character (sampled) | n/a |
| Modal entrance | Backdrop fade-in + scale-up | ~300ms | `ease-emphasized` (PrimeReact default) |
| Loading spinner | Custom red curve glyph rotates | continuous | `linear` |

What does **not** animate: scroll-triggered reveals, parallax, card hover lifts, cursor effects.

---

## Reduced motion

Always respect `prefers-reduced-motion`. The documented behaviour:

- Hero carousel auto-rotation pauses; user can still swipe.
- Partner marquee pauses entirely.
- Modal entrance fades only — no scale.
- All transitions on interactive elements drop to `0.01ms`.

```css
@media (prefers-reduced-motion: reduce) {
  *,
  *::before,
  *::after {
    animation-duration: 0.01ms !important;
    animation-iteration-count: 1 !important;
    transition-duration: 0.01ms !important;
  }
}
```

This is included globally in [src/styles/global.css](../src/styles/global.css).

## CSS custom properties

```css
/* Durations */
var(--duration-fast)            /* 150ms */
var(--duration-normal)          /* 200ms */
var(--duration-slow)            /* 300ms */
var(--duration-slower)          /* 500ms */

/* Easings */
var(--ease-out)
var(--ease-in-out)
var(--ease-emphasized)

/* Preset transitions */
var(--transition-colors)
var(--transition-hover)
```

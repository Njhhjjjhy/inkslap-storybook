# Iconography

Inkslap currently ships **two icon libraries simultaneously** — Phosphor Icons (inline SVG) and PrimeIcons (a font icon set). This is drift to resolve, not a feature. The documented system standardises on **Phosphor Icons** as the canonical library.

---

## Canonical library

**Phosphor Icons** — `regular` weight. Available at [phosphoricons.com](https://phosphoricons.com). MIT-licensed, ships as inline SVG with a `viewBox` of `0 0 256 256`.

### Why Phosphor

- Already in use across the live site (header cart, search magnifier, chevrons, gallery glyphs).
- Inline SVG — colour inherits from `currentColor`, sizes scale cleanly with `em` or `px`.
- Six weights available (`thin`, `light`, `regular`, `bold`, `fill`, `duotone`). The system uses `regular` for everything.
- Comprehensive set covering commerce, design, navigation, status, and content categories.

### What to drop

**PrimeIcons** classes (`pi-search`, `pi-chevron-right`, `pi-bolt`, `pi-palette`, `pi-shield`) currently appear inside PrimeReact components. Replace these with Phosphor equivalents during component refactor. PrimeIcons should not be referenced in new code.

## Rules

| Rule | Detail |
|------|--------|
| One library | Phosphor only. Replace PrimeIcons usages during refactor. |
| One weight | `regular` for all interface icons. `fill` only when the icon represents a selected state. |
| Inherits colour | Icons use `currentColor`. Do not hard-code fills. |
| Sparkle exception | The Inkslap sparkle is a custom 4-point glyph, not Phosphor's `sparkle`. Use it only as the brand mark, never as a generic interface icon. |
| Touch targets | Icons inside interactive controls require a 44 × 44 px hit area, even if the visible glyph is smaller. |
| No mixed treatments | Do not mix Phosphor `regular` with `fill` or `duotone` on the same surface. |

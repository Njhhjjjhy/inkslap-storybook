# Typography

The Inkslap type system pairs **Inter** (Latin) with **Noto Sans TC** (Traditional Chinese) and uses both at the same weights. The live site uses Noto Sans TC for everything — the documented system promotes Inter as the canonical English face with Noto Sans TC as the zh fallback.

The two faces share the same weight axis (400 / 500 / 600 / 700) so they pair predictably. **Inter** is positioned first in the font stack; **Noto Sans TC** handles glyphs Inter cannot render.

```css
--font-family-body: 'Inter', 'Noto Sans TC', system-ui, sans-serif;
--font-family-zh: 'Noto Sans TC', 'Inter', system-ui, sans-serif;
```

## Bilingual pairing

When English and Chinese appear on the same surface, the same weight applies across both. The line height is the **same px value**, not the same multiplier — Noto Sans TC's cap height differs from Inter's.

<div style={{ marginTop: '16px', padding: '24px', backgroundColor: '#F9F9F9', borderRadius: '12px' }}>
  <div style={{ fontFamily: 'Inter, sans-serif', fontSize: '24px', lineHeight: 1.2, fontWeight: 700, color: '#040404' }}>The most trusted corporate gifting platform</div>
  <div style={{ fontFamily: '"Noto Sans TC", sans-serif', fontSize: '20px', lineHeight: 1.4, fontWeight: 500, color: '#6C6C6C', marginTop: '6px' }}>最受信賴的企業禮贈品平台</div>
</div>

The English form sits at the documented heading size; the Chinese reads one step down, in `--color-text-muted`. This is the documented bilingual stacking pattern. See **Guidelines → Bilingual**.

## Casing

| Element | Casing | Example |
|---------|--------|---------|
| Wordmark | lowercase | `inkslap` (closed asset, do not retypeset) |
| Brand name in body | title case | `Inkslap`, `Inkslap's platform` |
| Headlines | sentence case | `The most trusted corporate gifting platform` |
| Body text | sentence case | `Upload your logo to see an instant preview.` |
| Buttons | sentence case | `Upload your logo`, `Talk to sales` |
| Labels | sentence case | `Email`, `Quantity`, `Order type` |
| Acronyms | uppercase | `UV`, `MOQ`, `API`, `ERP`, `KPI` |

**Italics are not used anywhere.** The face does not ship an italic variant in the documented stack. If emphasis is needed, use weight (500) instead.

## Letter spacing

Tighten as size grows. Open up at the smallest sizes.

| Token | Value | Used at |
|-------|-------|---------|
| `letter-spacing-tight` | `-0.02em` | display, h1 |
| `letter-spacing-snug` | `-0.01em` | h2 |
| `letter-spacing-normal` | `0` | h3–h5, body |
| `letter-spacing-wide` | `0.04em` | uppercase acronyms, micro labels |

## CSS custom properties

```css
/* Families */
var(--font-family-display)   /* Inter primary, Noto Sans TC fallback */
var(--font-family-body)      /* same as display */
var(--font-family-zh)        /* Noto Sans TC primary */
var(--font-family-mono)      /* monospace */

/* Weights */
var(--font-weight-regular)   /* 400 */
var(--font-weight-medium)    /* 500 */
var(--font-weight-semibold)  /* 600 */
var(--font-weight-bold)      /* 700 */

/* Sizes */
var(--font-size-display)     /* 40px */
var(--font-size-h1)          /* 40px */
var(--font-size-h2)          /* 28.8px */
var(--font-size-h3)          /* 24px */
var(--font-size-h4)          /* 20px */
var(--font-size-h5)          /* 16px */
var(--font-size-body-lg)     /* 18px */
var(--font-size-body)        /* 16px */
var(--font-size-body-sm)     /* 14px */
var(--font-size-caption)     /* 12px */
var(--font-size-micro)       /* 11px — floor */
```

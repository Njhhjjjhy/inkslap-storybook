# Navigation

The site has four navigation surfaces: header (every page), catalogue sub-nav, catalogue sidebar, and footer. The live site implements these as bare `<li>` elements without `<a>` wrappers — a critical a11y bug documented under **Audit → Findings** item 10. This page documents the **correct** implementation.

### Anatomy

| Part | Token | Notes |
|------|-------|-------|
| Background | `--color-base-white` | Solid white. |
| Border-bottom | `1px solid var(--color-border-default)` | Single hairline. |
| Height | 47–48 px | Tight, content-driven. |
| Logo | `inkslap` SVG, 73 × 18 px | Wraps an `<a href="/">`. |
| Nav links | `<a>` elements, 14 px / 500 weight | **Always `<a href>`, never bare `<li>`.** |
| Search | 36 × pill, `--color-neutral-100` background | Animated placeholder hints. |
| Bag icon | Phosphor cart, 22 × 22 inside 44 × 44 hit area | Shows count badge when items present. |
| Sign in / Sign up | Outlined + filled-black button pair | 8 × 14 padding, 4 px radius. |
| Language toggle | Pill-pair, brand-blue active | See **Guidelines → Bilingual**. |

### States

- **Active page:** the corresponding nav link is rendered with `--font-weight-semibold` and a 2-px brand-blue bottom border.
- **Hover:** link colour shifts to `--color-brand-blue`.
- **Focus:** `--shadow-focus` ring on the link, no underline.

### Contrast note

White text on Inkslap Blue is 3.3:1 — borderline for body, passes for large text. The documented footer uses **15 px / 600 weight** to qualify as "large text" and keep the brand colour. The live site uses 13 px which fails AA. See **Audit → Findings** item 13.

## Mobile navigation

On viewports under 768 px, the primary nav collapses behind a hamburger trigger. The pattern:

1. Replace inline nav with a single hamburger button (Phosphor `list` icon, 24 × 24 inside 44 × 44 hit area).
2. Tapping opens a full-height drawer from the right.
3. Drawer shows the same nav items as a vertical stack, plus the language toggle and the sign-in / sign-up pair.
4. The bag icon stays in the header at all viewports.
5. Drawer dismisses with `Escape`, clicking the backdrop, or the X button.

## Rules

| Rule | Detail |
|------|--------|
| Every nav item is an `<a href>` | No bare `<li>onclick</li>`. No `<div role="button">`. |
| Real URLs, not handlers | Right-click "open in new tab" must work. |
| Active state is visible | Bottom border, weight, or colour change. Never just a colour at sub-AA contrast. |
| Hamburger collapses below 768 px | The header items don't fit; collapse to a drawer. |
| Language toggle on every page | Header, persistent. |
| `<nav>` element with `aria-label` | Each navigation region (`Primary`, `Footer`, `Breadcrumb`) has its own labelled landmark. |

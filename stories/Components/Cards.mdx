# Cards

Cards are the workhorse component on the live site — product cards, feature cards, milestone cards, summary cards, modals. They share a common pattern: a single resting shadow, 12 px corner radius, and 24 px internal padding.

## Anatomy

| Part | Token | Notes |
|------|-------|-------|
| Background | `--color-bg-elevated` (`#FFFFFF`) | Solid white. No translucent fills. |
| Border radius | `--radius-lg` (12 px) | Cards with images may use 0 px top + 12 px bottom on the image wrapper. |
| Shadow | `--shadow-card-rest` | Rest state. |
| Shadow on hover (if interactive) | `--shadow-card-hover` | Only when the card is interactive. Don't add hover shadow to static cards. |
| Padding | `--space-6` (24 px) | Default. Tight cards may use `--space-4` (16 px). |
| Title | `font-size-h5` (16 px) / 700 | Inter / Noto Sans TC. |
| Body | `font-size-body-sm` (14 px) / 400, `--color-text-secondary` | Two to three lines max. |

---

## States

| State | Treatment |
|-------|-----------|
| Default | `--shadow-card-rest` |
| Hover (interactive cards) | `--shadow-card-hover`; transition `--transition-hover` |
| Focus (interactive cards) | `--shadow-focus` ring |
| Pressed | No transform; slight darken on background (`--color-neutral-50`) |
| Selected | 2-px solid `--color-brand-blue` border, internal padding shrinks by 2 px to compensate |
| Loading | Skeleton placeholder; no spinner inside the card |

## Anti-patterns

<div style={{ display: 'grid', gridTemplateColumns: '1fr 1fr', gap: '24px', marginTop: '24px' }}>
  <div style={{ padding: '20px', backgroundColor: '#F0FDF4', borderRadius: '8px', borderLeft: '4px solid #19B64E' }}>
    <strong style={{ color: '#0F7D34' }}>Do</strong>
    <ul style={{ margin: '12px 0 0 0', paddingLeft: '20px', color: '#040404' }}>
      <li>Use a single shadow per card.</li>
      <li>Apply hover shadow only when the card is interactive.</li>
      <li>Keep card titles to one line.</li>
      <li>Use a consistent radius across all cards in a grid.</li>
    </ul>
  </div>
  <div style={{ padding: '20px', backgroundColor: '#FFF7EE', borderRadius: '8px', borderLeft: '4px solid #D03131' }}>
    <strong style={{ color: '#D03131' }}>Don't</strong>
    <ul style={{ margin: '12px 0 0 0', paddingLeft: '20px', color: '#040404' }}>
      <li>Layer multiple shadows for "extra depth".</li>
      <li>Use coloured borders (brand-blue or other) on resting cards.</li>
      <li>Nest cards inside cards.</li>
      <li>Use gradient or image backgrounds on standard cards.</li>
    </ul>
  </div>
</div>

# Buttons

The live site has three competing button systems for primary actions. The documented system collapses them to **one canonical primary** (filled brand-blue, 600 weight, 8 px radius) and one secondary (outlined blue), with size variants for hero, default, and card contexts.

See **Audit → Findings** item 5 for the drift detail.

---

## Primary (canonical)

The default action on every page. Filled brand-blue, white text, 8 px radius. The signature brand-tinted shadow is **optional** — apply it to the most prominent primary on the page.

| State | Treatment |
|-------|-----------|
| Default | `--color-brand-blue` fill |
| Hover | Background darkens ~10% (`#007BC2`); cursor changes to pointer |
| Focus | `--shadow-focus` ring (`0 0 0 2px #FFFFFF, 0 0 0 4px #0099DE`) |
| Active | Background darkens ~20% briefly, no transform |
| Disabled | `#6CA0BD` fill, `cursor: not-allowed`, opacity 100% (not 50%) |
| Loading | Spinner replaces label, button width preserved, click disabled |

## Anti-patterns

<div style={{ display: 'grid', gridTemplateColumns: '1fr 1fr', gap: '24px', marginTop: '24px' }}>
  <div style={{ padding: '20px', backgroundColor: '#F0FDF4', borderRadius: '8px', borderLeft: '4px solid #19B64E' }}>
    <strong style={{ color: '#0F7D34' }}>Do</strong>
    <ul style={{ margin: '12px 0 0 0', paddingLeft: '20px', color: '#040404' }}>
      <li>Use one primary CTA per section.</li>
      <li>Pair primary with secondary, not two primaries.</li>
      <li>Use the signature shadow for the page's most important action.</li>
      <li>Keep button labels under 4 words.</li>
    </ul>
  </div>
  <div style={{ padding: '20px', backgroundColor: '#FFF7EE', borderRadius: '8px', borderLeft: '4px solid #D03131' }}>
    <strong style={{ color: '#D03131' }}>Don't</strong>
    <ul style={{ margin: '12px 0 0 0', paddingLeft: '20px', color: '#040404' }}>
      <li>Use the orange sparkle as a button colour.</li>
      <li>Use uppercase labels.</li>
      <li>Use exclamation points.</li>
      <li>Mix the three legacy button systems (product-detail black-outlined, services blue-filled, home `#0D95DE`-filled). Stick to the canonical primary.</li>
      <li>Bake CTAs into hero images as bitmaps.</li>
    </ul>
  </div>
</div>

# Forms

Form inputs share a consistent height (45 px), 16 px text, and a visible (not placeholder) label. The live site uses placeholder-only labelling — this is documented as drift in **Audit → Findings** item 11.

## Rules

| Rule | Detail |
|------|--------|
| Visible labels | Every input has a `<label>` above it. Placeholder-only labelling is banned. |
| 45 px height | All single-line inputs are 45 px tall. |
| 8 px radius | All inputs share `--radius-md`. |
| Helper text below | Use `aria-describedby` to link helper text to the input. |
| Error visible + announced | Errors use `aria-invalid="true"` + red border + message text. |
| Required marker | `<span aria-hidden="true">*</span>` in `--color-interaction-error` after the label. |
| Touch-friendly | Inputs are 45 px tall, comfortably above the 44 px touch-target minimum. |

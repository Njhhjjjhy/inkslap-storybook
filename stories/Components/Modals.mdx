# Modals

Inkslap uses three modal patterns: an **auth modal** (sign in / sign up), a **forced-action dialog** (errors that require attention), and an **image lightbox** (product gallery zoom). All share the same Material-style elevation 24 shadow and 16 px corner radius.

---

## Image lightbox

Used for product image zoom. Full-viewport overlay with the image centred.

| Part | Behaviour |
|------|-----------|
| Backdrop | `rgba(0, 0, 0, 0.9)` solid, no padding |
| Image | Centred, max 90% viewport width and height |
| Close | X button top-right, white on dark, 40 × 40 hit area |
| Navigation | Left and right arrows centred vertically, circular 40 × 40 buttons |
| Keyboard | `Escape` to close, `←` `→` to navigate |
| Pinch / zoom | Native browser zoom enabled |

## Common behaviour

All modals share:

| Behaviour | Implementation |
|-----------|----------------|
| Focus trap | Tab cycles within the modal. First focus on the primary input or CTA. |
| Backdrop dismiss | Click backdrop to dismiss — except on forced-action dialogs. |
| Escape key | Closes the modal (except forced-action). |
| Background scroll lock | `<body>` gets `overflow: hidden` while modal is open. |
| Entrance animation | Backdrop fades in 200 ms `--ease-emphasized`; modal scales from 0.95 to 1.0 + fades in. |
| Exit animation | Reverse of entrance, 150 ms. |
| Reduced motion | Animations replaced with instant show/hide. |
| ARIA | `<div role="dialog" aria-modal="true" aria-labelledby="...">` with focus moved to the title. |

## Anti-patterns

<div style={{ display: 'grid', gridTemplateColumns: '1fr 1fr', gap: '24px', marginTop: '24px' }}>
  <div style={{ padding: '20px', backgroundColor: '#F0FDF4', borderRadius: '8px', borderLeft: '4px solid #19B64E' }}>
    <strong style={{ color: '#0F7D34' }}>Do</strong>
    <ul style={{ margin: '12px 0 0 0', paddingLeft: '20px', color: '#040404' }}>
      <li>Trap focus inside the modal.</li>
      <li>Allow `Escape` to close (except forced-action).</li>
      <li>Move focus to the title or first input when opened.</li>
      <li>Return focus to the trigger element when closed.</li>
    </ul>
  </div>
  <div style={{ padding: '20px', backgroundColor: '#FFF7EE', borderRadius: '8px', borderLeft: '4px solid #D03131' }}>
    <strong style={{ color: '#D03131' }}>Don't</strong>
    <ul style={{ margin: '12px 0 0 0', paddingLeft: '20px', color: '#040404' }}>
      <li>Open a modal on page load (unless gating the session).</li>
      <li>Nest modals.</li>
      <li>Use modals for non-blocking notifications — use a toast.</li>
      <li>Omit the close button on auth dialogs.</li>
    </ul>
  </div>
</div>
